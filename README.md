# Kaspa Mining Suit 2 - Community App

Umbrel Community App Store for Kaspa Mining Suite 2.0.

Add this repository URL under **App Store → Community App Stores** on Umbrel:

https://github.com/NoillioN-Labs/kaspa-mining-suit-2-community-app

Open this community store and install **Kaspa Mining Suite 2.0**. Use the app password shown by Umbrel. The dedicated Kaspa node must synchronize before miners can connect.

UI: **5560** · miner Stratum: **55556** · node P2P: **16121**. The app uses its own data directories. Both services use the same immutable container image digest.

This is a development preview. Physical Umbrel and ASIC acceptance is still pending. Verify resources and ports before installation; change miner endpoints only when ready. Never enter wallet seeds or private keys.
